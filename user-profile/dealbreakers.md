## Strong red flags to discuss

These are not automatic rejections unless the user marks them as dealbreakers.

- Unclear employment model
- Compensation far below stated minimum
- Location or work authorization mismatch
- Excessive unpaid take-home work
- Very short termination window without practical safeguards
- Recruiter avoids direct answers to basic employment questions
- Role expectations conflict with stated work-life boundaries
- Job description emphasizes urgency without clarity

## How to report red flags

Always phrase concerns practically, not emotionally.

Example:

`This is not an automatic no, but it is a meaningful risk because [specific concern] conflicts with [candidate preference or practical constraint].`
