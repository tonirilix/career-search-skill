# Interview Stories

Use this file to store reusable stories for behavioral, technical, cultural, and leadership interviews.

Each story should include:

- Context
- Why it mattered
- Candidate's role
- Technical or product decision
- Tradeoff
- Collaboration/influence
- Outcome
- Reflection

## Universal answer structure

Use this structure for behavioral interviews:

1. `A strong example is...`
2. `What I personally owned was...`
3. `The main tradeoff was...`
4. `To move it forward, I had to align...`
5. `The outcome was...`
6. `What I learned from that was...`

Modify this wording to match the candidate's calibrated writing/speaking style.
