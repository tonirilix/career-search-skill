# User Profile

This folder is the candidate source of truth.

Before running serious job-search workflows, the agent should help the user fill these files through guided intake. Do not assume the defaults, examples, or placeholders are facts about the candidate.

## Files

- `resume.md`: resume content or parsed resume notes
- `career-profile.md`: professional positioning and background
- `preferences.md`: role, location, company, and work model preferences
- `compensation.md`: expectations and compensation logic
- `writing-style.md`: tone and drafting preferences
- `strengths-and-gaps.md`: what to emphasize and what not to overclaim
- `stories.md`: interview stories and career wins
- `dealbreakers.md`: hard filters and red flags
- `target-companies.md`: companies to prioritize, avoid, or watch
- `references.md`: references and work verification notes

## Operating rule

If a claim is not in this folder, in the resume, or explicitly provided by the user, do not use it as fact. Ask, mark as assumption, or leave it blank.
