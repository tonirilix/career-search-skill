# Workflow: Interview Prep

## Goal

Prepare the candidate for a specific interview stage using company, role, candidate, and process context.

## Inputs

- Role analysis
- Company research
- Interview stage
- Recruiter notes
- Candidate stories
- Strengths and gaps
- Previous interview feedback

## Interview types

- recruiter screen
- hiring manager screen
- technical deep dive
- live coding
- system design / architecture
- behavioral / all-around
- CEO/founder cultural
- offer / closing conversation

## Output path

```text
workspace/outputs/interview-prep/<company>-<stage>.md
```

Also update:

```text
workspace/data/companies/<company>/interviews.md
```

## Required sections

- What they are likely evaluating
- Candidate positioning
- Likely questions
- Strong answer drafts
- Stories to use
- Questions to ask them
- Red flags to observe
- Short prep summary

## Style

Answers should sound speakable, not like essays.

For cultural/founder interviews:

- connect motivation to product, craft, and ownership
- avoid sounding performative
- do not pretend to be someone else
- show ambition with grounded examples

For technical interviews:

- identify expected difficulty
- define practice focus
- prepare concise explanations
- highlight tradeoffs and reasoning

## Follow-up

After the interview, ask the user to paste notes and update:

- what was asked
- what went well
- concerns
- next stage
- thank-you/follow-up draft if useful
