# Workflow: Weekly Review

## Goal

Create a concise operating review of the job search.

## Inputs

- `data/pipeline.json`
- company process files
- next actions
- recent drafts
- deadlines

## Output path

```text
outputs/reports/weekly-review-<date>.md
```

Update:

```text
data/next-actions.md
```

## Sections

- Current top opportunities
- Active interviews
- Offers / deadlines
- Applications submitted
- Follow-ups due
- Roles to deprioritize
- Main risks
- Recommended focus for the week

## Weekly review tone

Be practical and prioritization-focused. Avoid motivational filler.

## Example recommendation format

`Prioritize [highest-leverage process] and [deadline-sensitive item]. Deprioritize [low-value activity] unless [clear condition] changes.`
