# Workflow: Decision Support

## Goal

Help the candidate make a clear decision between active opportunities.

## Inputs

- Pipeline
- Offer analyses
- Candidate preferences
- Compensation profile
- Company research
- Interview notes
- Personal constraints

## Compare across dimensions

- Compensation after realistic adjustments
- Employment stability
- Benefits
- PTO/sick time
- Legal/tax/admin burden
- Role fit
- Stack fit
- Career growth
- Company quality
- Team/manager confidence
- Mission interest
- Risk tolerance
- Timing/deadlines

## Output path

```text
outputs/reports/decision-memo-<date>.md
```

## Output structure

- Decision context
- Options
- Side-by-side comparison
- Best case for each option
- Main risks for each option
- Recommendation
- What would change the recommendation
- Next action

## Decision style

Be direct but not absolutist. If the recommendation depends on unknowns, state the unknowns clearly.

Example:

`Based on confirmed compensation and current contract terms, Option A is financially stronger. Option B could become competitive only if the final offer reaches X and includes Y.`
