## Draft quality checklist

Before finalizing a draft, check:

- Does it sound like the candidate?
- Does it avoid unnecessary repetition?
- Does it avoid overexplaining?
- Does it preserve the candidate’s true level?
- Does it have a clear ask or next step?
- Would the candidate feel comfortable sending it as-is?

## Default rule

If writing style is not calibrated, generate 2-3 tone options and ask the user which direction feels closest.
