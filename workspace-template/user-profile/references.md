## Reference request rules

When a company asks for references, clarify:

- Do they need former managers specifically?
- How many references?
- Can former colleagues count?
- Are certificates in another language acceptable?
- Should references be from different companies?

## Privacy rule

Never include personal phone numbers or email addresses in generated drafts unless the user explicitly provides and approves them.
